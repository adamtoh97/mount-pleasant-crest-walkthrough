# Mount Pleasant Crest walkthrough

Interactive 3D home and interior proposal for Blk 104A, #41-163.

- [Explore the walkthrough](https://adamtoh97.github.io/mount-pleasant-crest-walkthrough/#living)
- [Read the interior proposal](https://adamtoh97.github.io/mount-pleasant-crest-walkthrough/Mount_Pleasant_Crest_Interior_Proposal.html)

Drag to look around, use WASD to walk, or choose a room. Dollhouse and floor-plan views are also available. The walkthrough includes the drone reference, window reference, furniture proposal and bathroom mirrors.

## Model notes

Revision 4 uses a 2.60 m planning ceiling and the approved ceiling-wall / upper-pane / middle-pane / lower-pane / floor-wall ratios of 0.6 / 0.5 / 1.4 / 0.8 / 1. The exact delivered dimensions are unverified. Outdoor perspective, depth and peripheral framing are approximate; the drone clip is not a surveyed 360-degree capture.

The main bedroom has a front window and a solid side wall. The service yard faces a blank wall. Bedrooms 2 and 3 are arranged as a guest bedroom and a study/guest room. The household-shelter door leaf is omitted in the simulation. The decorative sticks have been removed from the dining table and kitchen counter.

## Hosting

This is a static site without a build step. GitHub Pages serves the `main` branch at its root. `index.html` is self-contained, with embedded model and media assets. The original walkthrough filename redirects to the same page while preserving the selected room.
